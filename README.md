## En bref

J'ai commencé par le front-end : des interfaces claires, accessibles, qui disent à l'écran ce qu'il faut faire. Aujourd'hui je construis des **applications complètes** : authentification, base de données, paiement, emails, back-office, tests de bout en bout et mise en production.

Ce qui me distingue : je pense **produit** avant de penser fichiers. Je cadre le besoin, je documente les décisions, puis je livre quelque chose qui tient sur mobile comme sur desktop, et qui reste lisible six mois plus tard.

**3 700+ contributions sur la dernière année**, dont la majorité sur des dépôts privés.

## Ma façon de travailler

- **Le besoin d'abord.** Je mets de l'ordre dans le besoin avant de mettre de l'ordre dans les fichiers.
- **Des écrans qui répondent à une question.** Une page simple et juste vaut mieux qu'une interface brillante mais confuse.
- **Les états qu'on oublie.** Mobile, erreur, vide, chargement, succès, accessibilité.
- **Des décisions écrites.** Architecture, conventions et choix techniques sont documentés dans le dépôt.
- **Vérifier avant de livrer.** Lint, typecheck, build, tests unitaires et E2E, intégration continue.
- **L'IA comme outil, pas comme pilote.** Je travaille avec des agents de code encadrés par des règles écrites, et je relis ce qui part en production.
